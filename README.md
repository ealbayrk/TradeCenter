## What this does

TradeCenter is a web-based algorithmic trading platform developed as a bachelor's graduation project.

The application brings together automated trading strategies, market monitoring, and virtual portfolio management in a unified environment.

Designed with a focus on Borsa Istanbul (BIST100), the project aims to make algorithmic trading more accessible through an intuitive interface.

**Focus:** Algorithmic Trading & Financial Technology  
**Platform:** Web Application  
**Status:** Completed Academic Project (2025)

---

## Key Features

- Automated trading strategies
- Portfolio and virtual wallet management
- Financial market monitoring
- Trading bot configuration
- Transaction history and performance tracking
- Price alerts and notifications
- User authentication and account management
